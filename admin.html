Koreksi lembar jawaban dengan AI

  1. Siapkan PDF lembar jawaban dengan nama file = NIM (mis. 27250001.pdf, 2 halaman per mahasiswa).
  2. Klik Salin prompt batch → buka chat baru Claude.ai → tempel prompt + lampirkan ke-10 PDF → kirim.
    Jika lampiran ditolak karena terlalu banyak: kirim prompt + sebagian PDF dengan tambahan kata TUNGGU, kirim sisa PDF di pesan berikutnya, lalu tulis NILAI SEKARANG.
  3. Salin seluruh balasan JSON → tempel di bawah → Proses batch → periksa yang bertanda merah → Simpan semua.
2. Buka Claude.ai ↗
  1. Klik Salin prompt koreksi (berisi soal, kunci & rubrik khusus NIM ini).
  2. Buka chat baru di Claude.ai, tempel prompt, lampirkan foto lembar jawaban, kirim.
  3. Salin balasan JSON dari Claude, tempel di kotak bawah, klik Proses hasil.
2. Buka Claude.ai ↗
Foto dikirim langsung ke Claude API. Biaya ditagih per pemakaian ke akun API Anda.
